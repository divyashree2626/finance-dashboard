 Finance Dashboard UI

A modern and responsive Finance Dashboard designed using Figma and developed using pure HTML, CSS, and JavaScript.

 Features

*  Dashboard Overview with Summary Cards (Balance, Spending, Savings)
*  Time-based data visualization (Monthly chart)
*  Category-based insights (Food, Taxi, Online Shopping)
*  Transaction history with details
*  Light & Dark Mode toggle
*  Fully responsive design (Mobile + Desktop)
*  Clean and user-friendly UI/UX

Tech Stack

* HTML5
* CSS3 (Custom styling with variables)
* JavaScript (DOM manipulation & interactions)
* Chart.js (for data visualization)
* Iconify ( for Icons)
* Unsplash (for images)
* Figma (UI/UX Design)
